# Arduino Course

Sketches from Paul McWhorter's "All New Arduino R4 WiFi Lessons for Absolute Beginners" YouTube series, followed on an Arduino Uno R3 with the Oku Electronics Beginners Kit.

Each folder is one sketch and was added as its own commit.

The sketches `CarChassis`, `BackMotorsTest`, `SerialMotorControl`, `FourWheelController` and `SavedCommandRepeater` are not from the series. They are test programs for a four-wheel Arduino Uno car (two L298N drivers) that I used while building a larger robot; `CarChassis/tools/turn_test.py` drives the car over serial.
